# youtube_researcher — исследовательская база из YouTube

Корпус полных транскриптов YouTube-роликов по темам + знания, извлечённые из них агентами.
Цель — чтобы ИИ-агенты, работающие над продуктами владельца (в первую очередь «Напарник»,
репозиторий `hellokittysoullja-bit/naparnik-site-adhd`), опирались на реальные знания экспертов.

## Структура
```
knowledge/references/<тема>.md   — СПРАВОЧНИКИ: правила, сведённые со всех роликов темы (читать первыми)
knowledge/conspects/<тема>_NN.md — подробные конспекты каждого ролика по порядку, с таймкодами
knowledge/notes/<тема>_NN.md     — заметки-знания аналитиков по пачкам роликов (промежуточный слой)
transcripts/<тема>/<id>.md       — полные транскрипты слово в слово, таймкоды каждые ~30 с
transcripts/index.tsv            — каталог: id, тема, название, канал, длительность, просмотры, язык, слова
data/ytr.sqlite.gz               — та же база в SQLite с полнотекстовым поиском (FTS5)
tool/                            — инструмент сбора и промпты агентов
```
Ссылка на момент ролика: `https://youtu.be/<id>?t=<секунды>`.

## Как искать
- Быстро по смыслу: открыть справочник темы, потом конспекты.
- Точная цитата: `grep -ril "слово" transcripts/` или `python3 tool/ytr.py grep "запрос"`
  (сначала `gunzip -k data/ytr.sqlite.gz && mv data/ytr.sqlite tool/`).

## Как собирать новую тему
1. `bash tool/setup.sh` (yt-dlp + генератор PO-токенов на :4416 — без него YouTube режет облачные IP).
2. Ключ YouTube Data API — в переменной окружения `YT_API_KEY` (настройки окружения → секреты).
   НИКОГДА не коммитить ключ. Без ключа поиск идёт через yt-dlp (хуже, но работает).
3. `python3 tool/ytr.py collect "запрос1" "запрос2" --n 25 --lang en --min-minutes 6 --topic <тема>`
   Темп ~30 роликов/мин, 4 потока. Бот-проверку YouTube проходит клиент mweb + PO-токены, запасной — android_vr.
4. `bash tool/mkchunks.sh <тема>` → пачки ~60k слов в tool/chunks/.
5. На каждую пачку — агент по `tool/analyst_prompt.md` (заметки) и `tool/conspect_prompt.md` (конспекты).
6. По всем заметкам темы — агент по `tool/synth_prompt.md` → справочник.
7. `python3 tool/export_md.py tool/ytr.sqlite transcripts`, `gzip -c tool/ytr.sqlite > data/ytr.sqlite.gz`, коммит.

## Правила отсева
По одному названию ролик НЕ выкидывать (владелец просил не отсевать жёстко). В `tool/excluded.txt`
только явно нетематические (например, «attention mechanism» из ML в теме про человеческое внимание).
Мусор помечает аналитик после чтения транскрипта целиком.

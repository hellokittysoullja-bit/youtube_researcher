[02:04] all the views perfectly in sync. I really like the simplicity of this approach. [02:35] current data design. But eventually I'm going to migrate everything to swift data and take advantage of the swift observation framework. [03:05] everything is wired together before I just take offthe-shelf packages for everything and abstract away the internals. One huge mistake I'm fixing with this app is not having a separate developer and production version of the app that I can install on the same

These kind of constraints make designing and implementing the UIs much simpler because everything is way more reusable and the number of decisions I have to make goes down.

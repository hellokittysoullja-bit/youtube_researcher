The answer is by reducing ux loads. So  there are primarily three types of ux loads: 

[02:20] visual load, motor load and the most spoken and  most famous cognitive load. Let's understand visual load. A user faces visual load when there  are multiple things in a user's viewframe with equal or same visual weightage. Due to this  excessive information, the user might miss on the relevant information and takes longer time to  process it. Due to this load we are not able to find out what are the things which will help us  to move forward. For example, hidden CTAs, i.e 

[02:54] your call to actions, your buttons being hidden  in the plethora of information provided on that particular screen. Next is motor load. Motor load  is associated with manual actions such as swiping, scrolling, clicking. So the click that we were  discussing or we are discussing that is a part of motor load. Next is cognitive load. Cognitive load  is associated with two things memory and thinking. It is the mental effort required to process and  store new set of information. Cognitive overload 

[03:30] happens when you receive so much of information  that your brain requires extra effort to process that set of information which sometimes leads  to frustration and compromised decision making. If we have to rank these loads in terms that how  they impact user experience the biggest culprit is cognitive load, followed by visual load, and the  last motor load. These were the three major ux loads. It is not practical to remove all the  three loads from the system but definitely we 

[04:04] should try to optimize these loads. Cognitive  load being the biggest culprit should be minimized the most therefore if it means that  we have to increase number of steps or clicks that is a motor load in order to  minimize thinking we should go for it.

Корпус собирается для базы знаний по дизайну цифровых продуктов (UI/UX, продуктовый дизайн, психология пользователя, внимание и мотивация, геймификация и гейм-дизайн, персонажи, тексты, онбординг, приложения для фокуса/привычек/СДВГ). Подтема этой партии: {TOPIC}.

Выпиши ТОЛЬКО id роликов, которые ЯВНО не имеют отношения ни к одной из этих областей — например: стройка, ремонт, рукоделие, кулинария, мебель, обзоры гаджетов как покупки, летсплеи и стримы без анализа дизайна, спорт, новости, музыкальные клипы, реклама/промо курсов без содержания, бытовые влоги.

Правило сомнения: если ролик МОЖЕТ содержать хоть что-то полезное для области (лекция по психологии, интервью с создателем продукта, разбор игры, личный опыт с СДВГ, обзор приложения) — НЕ выписывай его. Отсекаем только очевидный мусор. Лучше пропустить мусор, чем выкинуть полезное.

Запиши результат в {OUT}: одна строка — id через пробел (пустой файл, если отсеивать нечего). Ответь одной строкой: сколько всего роликов, сколько отсеяно, и 3–5 примеров отсеянных названий.

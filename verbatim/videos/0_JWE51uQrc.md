## 1. Ошибка: простым языком, с конструктивным выходом, заметно
`микрокопирайтинг · юзабилити` · [14:10](https://youtu.be/0_JWE51uQrc?t=850)

**Мысль:** Сообщение должно точно назвать проблему и предложить решение, иначе человек уйдёт гуглить код ошибки; визуально ошибка должна быть заметной.

**Слова автора:**

> You want to help number nine we want to help users recognize and diagnose and recover from errors happen right error message should Express in plain language not error codes precisely and indicate the problem and constructively suggest a solution if you make it so people don't understand how they can move forward they may have to Google an error code to find a forum with a solution those extra steps are going to drive people away if you provide a solution in a constructive way people can more easily recover from that from that error so error messages should be present with visual treatments that will help users notice and recognize them so providing that aesthetic an example is a wrong way sign on the road reminds drivers that they're headed in the wrong direction and ask them to stop right so something that's pretty critical hey pay attention I don't think you meant to do this by using digital error messages we can provide the same way of suggesting and rerouting people back to the actions they actually wanted to take and number 10.

**Для Напарника:** Ошибки сети/ИИ: голосом кота и со следующим шагом («попробуем ещё раз?»); про заметность не применимо: без тревожных красных акцентов и toast.

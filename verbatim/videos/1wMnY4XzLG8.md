## 1. Начинать с основ и аудита: 821 вариант отступа сократили до 8
`дизайн-система · процесс · отступы` · [02:39](https://youtu.be/1wMnY4XzLG8?t=159)

**Мысль:** Команда начала с сетки, цвета, типографики, иконок и провела аудит; число значений отступа упало с 821 до 8, иконок с 530 до 150, и система сама пошла в рост.

**Слова автора:**

> And of course it's to start with your foundations you want to start with your foundations for us this was grid color typography icons etc and you want to slowly work up through the complexity you don't want to go too fast you want to start slow just like you're building product and sometimes ripping up the floorboards can be really messy I'm so glad I get to use this slide it's one of my favorites she's so happy and for us it was like this we had 821 separate instances of space so developers were inputting manual space all over our product and you could see from page to page inconsistencies and spacing things would just kind of jump around through establishing a better system through thumbprint we were able to get that number down to eight four icons we went from 530 down to 150 to color and type so we would audit the system see what the mess was and think about a better system bringing in designers and developers and try to find a better way through the process and you'll find that this will snowball over time you'll set something out and developers will smell it they'll be like oh maybe I could use thumbprint for this maybe I could use thumbprint and save some time over here designers would say hey I think that's a little bit easier to use let me use that guideline in that pattern until other people about it so you'll find if you start with your foundation start small and communicate what they are you'll find that these will snowball over time.

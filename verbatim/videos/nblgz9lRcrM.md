**Слова автора:**

## 9. 5-минутная проверка: контраст 4.5:1, 16px, межстрочный 1.5, зум 200%
`доступность · типографика · цвет` · [15:50](https://youtu.be/nblgz9lRcrM?t=950)

**Мысль:** Быстрый чек-лист: контраст не менее 4.5:1 (на деле это уровень AA), база около 16px, интервал 1.5, масштабирование до 200% без поломки, относительные единицы.

**Слова автора:**

> A fantastic place to start is what the sources call the 5minute accessibility check. Super practical. First, check color contrast. Use a free online tool like the web AM contrast checker. You're aiming for WKG 2.1 level AAA compliance. That means a contrast ratio of at least 4.5 to1 for normal text. Makes things way easier to read. And don't rely only on color to convey info. >> Okay, contrast check. Got it. >> Next, look at text size and spacing. Is the base text size reasonable, like around 16 pixels? Is there enough space between lines? Maybe 1.5 times the text size? Crucially, can users zoom in 200% without text spilling off the screen or getting jumbled? Use relative units like RAM or M.

**Для Напарника:** Проверять текст Напарника на контраст 4.5:1 и масштаб 200%; использовать rem.

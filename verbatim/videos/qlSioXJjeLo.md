## 2. Характер должен соответствовать цели продукта и касаться всех его аспектов
`маскот · персонаж · крафт · вкус` · [06:54](https://youtu.be/qlSioXJjeLo?t=414)

**Мысль:** Поддерживающему роботу — мягкость; игровому спутнику ребёнка — плюшевость, поэтому его даже сделали полнее; самый футуристичный вариант не всегда лучший.

**Слова автора:**

> Because it's character it really fits with its goal it's a it's a healthcare robot it's a supportive robot so it should be should have this soft character and when I feel sad I can leave it like this big hug and with our office when we started to work on a robot for children like a playmate we also thought which character actually fits that goal not something futuristic it's it's like a teddy bear that fits so big soft huggable so when we try to design this robot we start to make it a little bit more fat we even gave it a little belly and when you when you start to look at this character in this way like it's the goal of the product to have this nice Assaf character it touches all the aspects of the product it's not anymore about running fast or standing on one leg but it has to be able to sit in a corner because that is that you have you play with these things you put them in the corner and then a little girl's gonna have a tea party with this robot so it should be able to do that and this character starts to touch all these aspects of the robot and the most futuristic option is not always the best option actually it can be much more simple for a character.

**Для Напарника:** Характер кота: мягкий, тёплый, присутствующий; это решение пронизывает форму, голос и анимацию.

## 4. Характер складывается из движения, формы и глаз вместе; глаза лишь поддерживают
`маскот · персонаж · анимация · крафт` · [10:19](https://youtu.be/qlSioXJjeLo?t=619)

**Мысль:** Робот-исследователь для детей любопытно оглядывается; ни форма, ни глаза по отдельности не создают характер.

**Слова автора:**

> Shows how this thing actually by turning its head and turning its body it looks around it's like it's searching for something and it gets a kind of technical kind of curious kind of this you see that like he's discovering something and it works best if you if you combine this with this sort of things so for example its eyes they're not the main thing that shows its expression but it does help to the ice actually supports character you'd be surprised look around like this but the main thing so all these things together all these things together actually create this character it's not only the movement it's not only the shape it's not only the eyes everything together we were aiming for this character something that looks around a bit that is searching things it's a curious robot that was the character we're looking for because this robot is actually education robot it wants to explore the world together with kids so the character really fits the function of this robot.

**Для Напарника:** Любопытство кота у костра: сочетание поворота головы, позы и взгляда; согласуется с дыханием существа в фоне.

## 5. Любая нестыковка ломает характер: мягкий персонаж с механическим движением не работает
`маскот · крафт · вкус` · [12:12](https://youtu.be/qlSioXJjeLo?t=732)

**Мысль:** Люди быстро замечают странность, поэтому каждый аспект должен поддерживать характер.

**Слова автора:**

> And the trick is of course these are not simple products they have really complex to get this character right if something is off then people notice really quickly that there's something strange a soft robot that has a very mechanical movement it doesn't work anymore so everything has to be right every aspect has to support this character.

**Для Напарника:** Анимации кота, звуки и тексты должны быть согласованы по теплоте; диссонанс заметнее, чем кажется.

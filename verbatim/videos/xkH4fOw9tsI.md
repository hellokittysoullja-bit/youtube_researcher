# Redesigning Delta's SkyMiles Page

**Канал:** UX Tools · 9 мин · субтитры: en (ручные) · https://youtu.be/xkH4fOw9tsI

> «Слова автора» — дословный текст из транскрипта (убраны только um/uh и заикания; в авто-субтитрах мало знаков препинания). «Мысль» и «Для Напарника» — вывод разметчика, это не речь автора.


---

## 1. Перегруженная страница: satisficing и закон Хика
`иерархия · внимание · дизайн-система` · [01:20](https://youtu.be/xkH4fOw9tsI?t=80)

**Мысль:** Когда пользователь перегружен, он бросает разбираться и берёт первое решение (satisficing); больше визуальных стимулов значит дольше обработка (Hick). Итог: ошибки, время, трение.

**Слова автора:**

> When you first land on this page it feels very busy and honestly kind of overwhelming and a little confusing so we know that's going to get in the way of the task that the user is trying to accomplish here because of things like satisficing which is where basically the user gets so overwhelmed that they just sort of give up looking at everything and they make the first decision that comes to mind or hicks law which is where the number of visual stimuli increases the amount of time it takes to process information and make decisions so a page that's confusing and isn't structured very well and doesn't have very much order is going to cause more user errors it's going to lengthen out the time that a user needs to accomplish their task and it's going to cause just a lot of friction.

**Для Напарника:** Для людей с СДВГ перегрузка критичнее: ограничивать число стимулов на Доме и Фокусе.


---

## 2. Мозгу нужен порядок: хаос тратит ресурс на разбор, а не на решение
`иерархия · дизайн-система · внимание` · [03:25](https://youtu.be/xkH4fOw9tsI?t=205)

**Мысль:** Разные кнопки, шрифты, оттенки и сбитые отступы отвлекают, так как мозг тратит силы на их обработку вместо принятия решений.

**Слова автора:**

> All of this type of stuff is just a little distracting for the brain the our brains like order and when order isn't present then the brain sort of has to process those things instead of doing things like processing information and making decisions.

**Для Напарника:** Единые стили кнопок, отступов и размеров на трёх экранах; проверять консистентность перед выпуском.


---

## 3. Группировка близостью, слияние дублей и иерархия действий
`иерархия · сетка · внимание` · [03:47](https://youtu.be/xkH4fOw9tsI?t=227)

**Мысль:** Закон близости: близкое мозг связывает; нужно убрать дублирующие заголовки и ссылки, ведущие в одно место, и выстроить иерархию действий, а не много разных кнопок.

**Слова автора:**

> There's quite a lot of information on this page which is great because the user is coming here to get information but some of it is duplicate information and a lot of it isn't grouped up very well so remember the law of proximity says that things that are close together our brain can associate better and process better so i think we need to tighten up the information a little bit also i'll give you a couple examples here the first one is this sky miles member title it's very big and they're too close together which feels like duplicate information i also don't know if we actually need this title because we're already on the sky miles page so there's kind of an assumption that it we're looking at a sky miles member profile also explore sky miles membership guide and program rules program details earn miles use miles all of those go to very similar or the same page so i think we can sort of simplify the number of links that go to information like that and my recent activity my account activity and account activity all go to the same or similar pages so i think we can simplify that as well and finally there are lots of actions you can take from this page like i said before there are several buttons all of which sort of look different but i mean there's no real hierarchy of what you should be doing except for maybe book a trip because it has more spacing and so it draws your eye more but there are buttons and links everywhere to all kinds of things so i think we need to build a better structure about the calls to action and things that the user can do on this page.

**Для Напарника:** На Доме один главный CTA; дубли (несколько путей к старту сессии) объединить, близкие по смыслу элементы сгруппировать.

## 4. Прогресс до следующего уровня: убрать аббревиатуры, показать «сколько осталось»
`геймификация · тексты · иерархия` · [06:21](https://youtu.be/xkH4fOw9tsI?t=381)

**Мысль:** Графики упрощены, расшифрованы аббревиатуры, ясно показано, сколько осталось до следующего уровня.

**Слова автора:**

> I simplified these charts a little bit so that they're easier to understand i got rid of the acronyms because i bet a lot of people don't know what the acronyms mean so like before it had mqms and i wrote that out instead of using the acronym this is supposed to clearly show you how long it will take you to get to the next tier so you know in this particular example they have 22 000 miles left to get to the silver tier.

**Для Напарника:** Мир: понятно показывать «сколько до следующего ориентира» простыми словами, без стыда и счётчиков-долгов.


---

## 5. Выводы: группируй, убирай дубли, сначала дай человеку нужное
`иерархия · процесс · дизайн-система` · [08:46](https://youtu.be/xkH4fOw9tsI?t=526)

**Мысль:** Группировать похожее, убирать дублирующую информацию и действия, снижать визуальный шум системой, сначала давать пользователю желаемое, потом просить своё.

**Слова автора:**

> Main takeaways that we can use in any design are group similar things together get rid of duplicate information and actions and reduce visual signals by using things like your design system everywhere on your app and then finally give the user what they want first before you ask for things from them and make sure that you understand why they're on this page and what exactly they need to accomplish and then help them achieve that task.

**Для Напарника:** Дом: сначала польза (тёплое приветствие, продолжить шаг), только потом вопросы (один вопрос за визит).

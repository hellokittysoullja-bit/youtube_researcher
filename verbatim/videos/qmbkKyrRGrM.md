## 2. Game feel: заметен, когда его нет, и незаметен, когда он есть
`вкус · крафт · анимация` · [03:27](https://youtu.be/qmbkKyrRGrM?t=207)

**Мысль:** Ощущение сделано из деталей, про которые игрок говорит просто это приятно, не зная почему. Отсутствие замечают сразу.

**Слова автора:**

> Game feel is that type of thing that makes you say this feels awesome but I don't know why is the thing that it's really obvious when it's not there but not many people notice it when it is there.

**Для Напарника:** Оправдывает вложения в микродетали отклика: пользователь их не назовёт, но заметит, если их убрать.

## 3. Повторяющиеся звуки: тише и с вариацией высоты вместо одного клипа
`звук · крафт · микрокопирайтинг` · [09:53](https://youtu.be/qmbkKyrRGrM?t=593)

**Мысль:** Одинаковый звук раздражает; снизить громкость и каждый раз слегка менять высоту, не создавая много файлов.

**Слова автора:**

> Some tips for movement sound effects it has to be subtle and there has to be a lot of variation now I am going to start with a jumping sound effect which sounds like this cool that sounds good but it's kind of annoying because it's the same sound so first of all I'm going to make it subtle so I'm going to lower the volume better but I want to add variation so what I could do is use multiple files but instead I'm going to Simply bend the pit every time it plays so it's way more awesome like this because I create additional stuff without using multiple files.

**Для Напарника:** Звуки Напарника (start sigh, костёр) играть с небольшим случайным сдвигом высоты и тихо, чтобы не приедались.

## 4. Слои эффектов вместе сообщают событие без взгляда
`анимация · хаптика · звук` · [14:06](https://youtu.be/qmbkKyrRGrM?t=846)

**Мысль:** Тряска экрана, хроматическая аберрация, звук, вибрация вместе дают ощущение, что можно понять событие, даже не глядя на место.

**Слова автора:**

> Awesome now the awesome thing about all this is that you can tell when somebody dies somewhere else on the screen without having to look there you simply see the screen shake and the chromatic aberration and they all come together.

**Для Напарника:** Для пика награды сочетать несколько тихих каналов (свет, звук, хаптика), а не одну громкую анимацию.

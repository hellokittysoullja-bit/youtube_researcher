# База знаний «живой профессионал»

Опыт практиков с YouTube — продуктовых дизайнеров Apple, Dropbox, Duolingo, Figma, Airbnb, нейроучёных, психологов,
людей с СДВГ, гейм-дизайнеров — **их собственными словами**. Собрана 2026-10-20 для проектирования Напарника
(и любых других продуктов владельца: сайт, личный бренд).

## Что здесь лежит

| Путь | Что это | Как читать |
|---|---|---|
| `INDEX.md` | Темы с числом фрагментов и ссылкой на файл | Всегда начинай отсюда |
| `by-tag/<тема>.md` | **Слова авторов дословно** по теме, из всех роликов подряд, с таймкодом и ссылкой | Основной файл для работы. Большие — читай частями до конца |
| `videos/<id>.md` | То же, но по одному ролику | Когда нужен контекст конкретного автора |
| `transcripts/<тема>/<id>.md` | **Полный** транскрипт ролика (все слова), таймкод каждые 30 с | Точная цитата, поиск: `grep -ril "фраза" knowledge/transcripts/` |
| `transcripts/index.tsv` | Каталог всех роликов: тема, канал, просмотры, оценка ценности, есть ли инсайты | Фильтры: `awk -F'\t' '$9=="высокая"' ...` |
| `references/<тема>.md` | Выводы, сведённые по многим роликам, с правилом «Для Напарника» и источниками | Быстрый обзор темы и спорные места |

## Что дословно, а что нет

- **Блок «Слова автора»** — точный текст из транскрипта. Убраны только слова-паразиты um/uh, заикания и теги вроде `[music]`.
  Выбор кусков делал разметчик, но слова берёт скрипт, и каждый фрагмент проверен: все слова присутствуют в транскрипте в том же порядке.
- **«Мысль»** и **«Для Напарника»** — вывод разметчика. Это интерпретация, а не речь автора. Правила проекта (`CLAUDE.md`) выше неё.
- Тексты `references/` — синтез по многим роликам: удобен, но это пересказ; за точностью иди в `by-tag/` и `transcripts/`.

## Ограничения (честно)

- Субтитры у большинства роликов — автоматические (YouTube). В них бывают ошибки в именах и терминах («жопе фай» вместо Shopify),
  мало знаков препинания. Тексты не правились — так остаются «слово в слово».
- 119 роликов, у которых не нашлось субтитров на языке автора (только машинный перевод), в `transcripts/` не включены.
- Часть статистики авторов не подтверждена. Цифры без источника считай «со слов автора».
- Совет автора может противоречить принципам продукта (стыд, сгорающие стрики, toast…). Где разметчик это заметил — стоит «не применимо».

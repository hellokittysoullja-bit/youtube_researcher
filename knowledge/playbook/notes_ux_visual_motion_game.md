# Заметки: ux-principles, visual-fundamentals, motion, mobile, behavioral, game-design, companion (все ролики, «Применимо»)

## Первая сессия / онбординг (сводка по всем темам)
- Онбординг = первое реальное действие, не слайды (Apple, Duolingo, PvZ2, Celeste). Объяснение острова — после первой завершённой сессии.
- Ничего не просить до первой ценности (имя, уведомления, аккаунт). «Не сейчас, всё хорошо» — тёплый отказ.
- Чипы-варианты вместо пустого поля (recognition > recall; Hick). Пошагово, один вопрос на экран, индикатор «где я».
- Endowed progress честно: первый визит уже даёт росток. Beginner's luck: первая сессия — заметная находка.
- Минимальная сессия 2–5 мин засчитывается как полная победа (Fogg starter step). Планка низкая → человек её превышает и празднуется превышение.
- Slide/hold-to-start — осознанный ритуал + защита от случайного тапа; дубль-кнопка.

## Финал / пик (Peak-End, game feel)
- Слоистый пик: hit-stop (микропауза) → свет от точки → рост с overshoot → частицы → звук → хаптика → реплика, которая НАЗЫВАЕТ шаг.
- Пропорциональность: 2 мин — тепло, но скромнее; первый ориентир — торжественно. Повторяемое — скипабельно.
- После пика — «скамейка у костра»: пауза, одно следующее действие, явная точка «можно идти».
- Прерванная сессия ничего не отнимает; кот: «шаг был великоват — давай меньше» (чини дизайн, не себя).

## Моушн
- Вход ease-out, уход ease-in и короче (250/150 мс). Чипы 70–150 мс, карточки ~250, хореография 700+. Только transform/opacity.
- Stagger: главная CTA появляется последней. Mask reveal для заголовка пика. Одна «подпись» easing на продукт.
- Кот: anticipation → новое выражение → settle; «speak hop» на новую реплику; дыхание ~12–16/мин, периферийное. Кот смотрит на главное действие (gaze cueing).
- Каждое состояние имеет обратный переход; pressed на мобиле обязателен; prefers-reduced-motion — off switch.

## Хаптика
- tick (пикер, только при смене) < light (старт) < medium (готово) < heavy/double (ориентир, редкость). iOS Safari: navigator.vibrate нет → трюк `<input type=checkbox switch>` + feature-detect. Тоггл «вибрация». Всегда визуальный дубль.

## Визуал
- Один акцент (≈10%) только на главном действии; grayscale/squint test — одно тяжёлое пятно.
- Тёмная тема: поверхности светлее фона шагом L 0.04–0.06, тинтованные hue неба; текст off-white 85–90%; без thin весов.
- Шкала 12/14/16/18/20/24/28/32; line-height кратно 4; отступы 4/8 шкала; внутреннее ≤ внешнего. Тач-цели ≥44–48, зазор ≥8–12.
- Кириллица: «ёлочки», —, неразрывный пробел после коротких предлогов.
- Выбранный чип — не только цветом (рамка/вес/галочка).

## Поведение / этика
- Fogg: B=MAP, при застревании сначала уменьшить шаг или задать момент, не «мотивировать». Shine сразу после.
- White hat (смысл, рост, выбор, владение), минимум black hat. Никаких стриков с обнулением, увядания, FOMO, бейджей, confirmshaming.
- IKEA: дать назвать/выбрать что-то своё — но опционально и легко.
- Nudge-plus: кот объясняет, почему предлагает («2 минуты — чтобы просто войти»).

## Кот
- Protégé, который не обуза; R2-D2, не C-3PO; одна характерная деталь; реплики вариативные и конкретные; всегда в образе (ошибки, загрузка, пустые состояния).

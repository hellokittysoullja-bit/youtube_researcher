# Выжимка: conspects/onboarding_01 (35 роликов) — что применимо к первому экрану и онбордингу Напарника

## Ядро
- Онбординг = путь от «оцениваю» к «пользуюсь регулярно»; цель — повторить ценность больше одного раза (Appcues). Не тур и не карусель (~90% жмут Skip — Malewicz).
- Ценность ДО любых просьб: спросить → дать ценность по ответу → только потом просить (Gleam-разбор: «весь онбординг — одни просьбы» = плохо). Duolingo: язык → вопросы о тебе → первый урок → радость завершения → только потом аккаунт (~60 экранов, но не ощущается длинным).
- Granola-правило (Tim Gabe): по умолчанию — максимально быстро к ощутимой ценности; длинный онбординг оправдан, только если покупает персонализацию первого опыта. Напарник — не продукт глубокой персонализации → минимум вопросов, сразу первая сессия.
- Welcome с ОДНИМ следующим действием (Userpilot: 40% SaaS без welcome; 99% кликают действие welcome-экрана). Приветствие задаёт тон отношений (ProductLed).
- Быстрая победа и её бурное празднование (Pulsate: «не "задача добавлена", а "ура, дай пять!"», и сразу мостик к следующей вехе).
- Ритуал обязательства: удержание пальца/отпечаток с хаптикой и анимацией (Gleam, Honk) — «удерживай, чтобы сесть рядом».
- Спрашивать только то, что меняет опыт; всегда вариант «не знаю / решу позже» (Lackner); мульти-выбор целей (Headspace +10%); разговорный копирайт квиза (DSC +5%); показать, что ответы «разблокировали» (Endless, Speak, BitePal).
- Каждая просьба — с выгодой «как это улучшит твой опыт» (Notion/Lyssna золотое правило).
- Сохранять шаг онбординга в localStorage на каждом шаге; возвращать на место (Lackner, Radzion).
- Никогда не вести в тупики; текущее доступное действие ярче прошлых (Gleam).
- Эмоциональный слой: idle-анимации маскота, реакции, «эмоции заразительны» (Duolingo DAU 14→34 млн после системы анимации персонажей, со слов автора); полировка = сигнал доверия (Phantom, Revolut).
- JTBD-силы (ProductLed ABC): усилить потребность, снять тревогу (у СДВГ главная — «опять не получится»), закрепить изменение (магическое число).
- Честно управлять ожиданиями (Cal AI: «первые дни медленно»).
- Отдельный UX для вернувшихся (Duolingo) — без упрёков.
- Ожидание с мини-анимацией маскота + тёплая фраза, не спиннер.
- «Записка основателя» / человеческое прикосновение (One Year, Basecamp, Airbnb).

## Конкретно для первого экрана/потока
1. Первый экран = приветствие кота + одна кнопка (как Duolingo «Привет! Я Duo!» + «ДАЛЕЕ»).
2. 1–2 вопроса с вариантами-чипами (что откладываешь; сколько есть сил) + «решу потом».
3. Экран «вот что будет» — ответы разблокировали план (например: «Сделаем первый шаг за 2 минуты: …»).
4. Ритуал: «Удерживай, чтобы начать» (hold-to-commit) → старт 2-минутной сессии.
5. Праздник первой победы + мостик к следующему.

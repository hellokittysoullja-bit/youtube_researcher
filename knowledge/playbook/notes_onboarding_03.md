# Заметки: onboarding_03 (прочитано целиком)

## Каркас
- Success path: Attract → Guide → Reward → Expand. Time-to-value < 60 с.
- «Мост ценности» (Jamie): совпадение с проблемой → результат → релевантность → доверие. Один смысл на экран, кнопка всегда внизу на одном месте.
- Front-loading (всё объяснить заранее) проваливается → guided interaction: человек делает, интерфейс подсказывает по ходу.

## Конкретные приёмы
- Chilli «Radar»: на входе одно действие + хаптика «нашёл» — первая победа в первые секунды.
- Kris Greenwald: чипы вместо пустых полей; умные дефолты; первую сессию можно 10–15 мин, но для СДВГ — 2 мин как вход.
- Appelune: каждый вопрос обязан менять то, что человек увидит дальше (иначе не спрашивать); предложение напоминания — сразу после первой сессии; после онбординга — сразу в первое действие, не на «домашний экран».
- Bear Liu: «продавай фаерболы» (что получишь), первый визит = разговор с новым другом, не анкета.
- Ionixx: «союзник, а не инструмент»; мотивировать прогрессом, не страхом.
- Particle: введённые значения остаются видны; прогресс виден с первого шага.
- Coda: пока человек читает — никаких всплывающих анимаций рядом; спросить первую цель.
- Fabulous — антипример: длинная продажа + пейвол до ценности.

## Для «Напарника»
- Вопросы онбординга: только те, что меняют план (что мешает начать / сколько есть сил). Плюс «решу потом».
- Экран плана показывает ответы человека («ты сказал: … → поэтому 2 минуты»).
- Сразу после первой сессии — празднование + мост «завтра продолжим?» (напоминание после ценности).

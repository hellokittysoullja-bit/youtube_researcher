# Выжимка: conspects/onboarding_02 (31 ролик)

- Aha = пересечение «что делают» и «кто остаётся» (Pendo). «Наклониться» к aha: Dropbox затемняет всё, кроме «+». Meaningful use = 3–4 раза, а не один.
- Три типа «новых»: новый; вернувшийся после перерыва; старый, впервые видящий фичу.
- Паттерны: аннотирующие (1–3 тултипа макс.), встроенные (модалки/чек-листы), выделенные (welcome/signup — «добавляют вес», но не затягивать).
- Day-one action (Hopper «Watching»): низкое усилие, высокая ценность, даёт повод вернуться. Сначала перестроить продукт, потом добавлять UI.
- «Продавать зонты под дождём» — ловить момент нужды («не могу начать»), сегментировать по потребности, не по «типу человека». Против фичеита: «уйди с дороги пользователя».
- Drift: первый шаг — лёгкая персонализация (цвет бренда) → «уже на полпути»; позитивная микрокопия при вводе; живое превью (Soapbox).
- Peak-end: финал онбординга — самый яркий момент (Lemlist — конфетти в конце).
- Convert: каждый вопрос обязан что-то менять для пользователя; «успех» должен ощущаться успешным.
- Slackbot = наш кот: гид в контексте; пустые состояния = мини-центры обучения.
- Self-directed learning: «guide on the side»; меньше выбора (Blue Apron — 2 плана).
- 1000 SaaS: 40% без welcome; 99% кликают действие welcome; контекстный онбординг по событиям (HubSpot «устали копировать?»).
- ATC: сразу в ключевой опыт (демо-эпизод), прайминг уведомлений превью настоящего уведомления, кнопки ~60px, fade-переходы, вспышка при выборе, «пропустить тишину» качнулась один раз.
- Uber-ситуация: человек «прямо сейчас» → минимум вопросов; трение — максимально поздно; не самооценка 1–5, а адаптация по поведению.
- DAD-тест (Direct, Add, Delight) для каждого шага; эффект IKEA (+60–80% ценности); вариант «пока не знаю» (Wave).
- «Земля обетованная» (Hulick): продукт виден за экранами онбординга → мотивация.
- How We Feel (ближайший референс): онбординг = первая реальная запись; хаптика на каждый появляющийся элемент; shared-element переходы; не просить вход посреди первого цикла; микрофон вместо печати; хаптика в ритме дыхания.
- Grammarly: дать «документ с ошибками» — живой пример вместо объяснения. Client Joy: новичку нужны «лёгкий старт + ранняя уверенность, что смогу».
- Marina Abramova: главная кнопка всегда на одном месте ~24px от home indicator; не «прыгает».
- Fabulous (антипример конкурента): поп-апы, смена визуального языка, «научно доказано», hold-to-confirm без хаптики и подписи.

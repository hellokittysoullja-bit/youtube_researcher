# Заметки: conversion-landing_01–04 (все ролики, раздел «Применимо»)

## Первый экран
- Формула hero: результат + снятое возражение + доказательство; ~6 слов; словами ЦА («не могу начать»).
- Первая фраза — о человеке, не о продукте («Похоже, задача висит уже давно?»).
- Один акцент, одна CTA, самый заметный = самый ценный. Squint test: кот не крадёт внимание у кнопки.
- Визуал — «жизнь после» (остров, спокойный кот), не пустой таймер. Лицо кота с эмоцией + CTA > CTA одна (mirroring).
- CTA с глагола и про желание/результат («Начать первое дело», «Попробовать 2 минуты»), не «Зарегистрироваться». Кнопка обязана немедленно дать обещанное — без лишних экранов между.
- Без поп-апов, чатов-виджетов, каруселей, автоплея, фейкового дефицита и таймеров.
- Повторный визит: CTA не прятать за intro-анимацией.

## Вход в продукт
- Квиз-вход 1–2 вопроса голосом кота («Что мешает начать?»), без диагнозов и «низкого балла»; big reveal = сильная сторона + один первый шаг → сразу Фокус.
- Ответы-кнопки от лица человека («Давай!», «Не сейчас»).
- Минимум решений: дефолтная длительность, готовый шаг; кот сам дробит задачу (закрывает «я не умею дробить»).
- Labor illusion для AI: «смотрю на задачу… режу на кусочки…» вместо спиннера; локальная реплика мгновенно, пока ждём AI.
- Объяснять неочевидное одной строкой у элемента в момент первой встречи, не туром.
- Экран done = не тупик: реплика о том, что изменилось на острове + одно следующее действие. Персональная реплика по имени — пик.
- Мир и чат раскрывать после первой победы (progressive disclosure).

## Голос
- Документ голоса кота: пары «X, но не Y»; тест «сказал бы кот это вслух?»; ошибки: факт → решение → тепло, без «упс».
- Диалоги: «Закончить сейчас / Посидеть ещё», не «Отмена/ОК». Разрешения — с выгодой для человека.
- Не использовать loss aversion, стыд, «тройные гарантии», фейковые отзывы.

## Метрики
- Главная конверсия — завершённая первая сессия; дальше D7-возврат. Трафик мал → наблюдение и смелые изменения, не A/B.

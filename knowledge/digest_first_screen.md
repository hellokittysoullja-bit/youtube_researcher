# Digest 01 — visual-fundamentals §1–5.9 (иерархия, пространство, сетка, композиция, типографика)

## Иерархия
- Сначала маршрут взгляда (вход → середина → выход), потом размеры. Финальная точка запоминается лучше всего (Peak-End).
- 3 уровня важности (hook / secondary / finishing). Больше — шум. На верхнем уровне ОДИН элемент «явно в одиночестве».
- Перепад между уровнями 2–3× (48/16, не 18/16). Малый шаг только внутри одного блока (цена 18 рядом с названием 16).
- Сигналы не спорят: главное = крупнее + жирнее + контрастнее. Сначала логическая важность, потом вес. Неправильная иерархия хуже никакой.
- Рычаги: размер, вес, цвет/контраст/прозрачность, позиция, пустое пространство вокруг, ориентация, глубина (блюр), движение (самый сильный), смена стиля шрифта.
- Деэмфаза вместо эмфазы: если главное уже на максимуме контраста, приглуши остальное (текст L100% / вторичный 60%).
- Одна главная кнопка отличается от альтернатив; больше 2 действий на экране = сигнал проблемы с иерархией.
- Тесты: прищур/блюр, 5 секунд, grayscale, дешёвый телефон. Иерархию нельзя рассчитать в голове.
- Сканирование: Z — разреженные/лендинг; F — плотный текст. Силовая линия: центральная ось заголовков.
- Якоря: каждый объект тяготеет к углу, центру или стороне модуля — иначе «висит».

## Пространство
- Пространство группирует сильнее размера и цвета. Внутренний отступ ≤ внешнего (штрих<буква<слово<строка<заголовок↔текст<край подложки).
- Линия сильнее близости: группируй пробелами, линия может переназначить связи.
- Воздух ≠ максимум пустоты: правильные отношения. Широкие интервалы = спокойные паузы, плотные = срочность.
- Ошибка группировки создаёт ложный смысл (подпись ближе к чужому блоку).

## Сетка
- Шкала 4/8 везде (4,8,12,16,24,32,40,48,64). Исключение 6px как полушаг. Резиновые ширины на сетку не ложатся.
- Мобайл: поля 16–24, секции 32, заголовок→контент 24, карточка 16, чипы 8, мин 6px.
- Колонки 12/8/4; сетке подчиняются контейнеры, не каждый элемент. Ломать сетку можно только картинкой и намеренно.
- Один левый край, не мешать центр и лево. Тап-цель ≥44–48px, зазор ≥8px.
- Вертикальный ритм: равные паузы между секциями.

## Композиция
- Баланс: вес = размер×контраст×форма×удалённость. Маленький яркий уравновешивает большой тусклый. Нечётное число (3,5) лучше чётного.
- Типы: классическая (безопасна), сеточная, асимметричная (вау, но не для возрастных), центрированная (один пик), диагональная (изюм).
- Фокус в сцене: контраст/насыщенность/размер/движение у ОДНОГО элемента + свет как указатель («игрок идёт на свет»). Притушить окружение. Виньетка склеивает сцену. Взгляд персонажа направляет зрителя.
- Новизна — комбинациями тех же правил, не новым правилом в каждом блоке.

## Типографика
- 1 гарнитура (макс 2), 2–3 начертания. Иерархия размером/весом/цветом/трекингом.
- UI-шрифт: большая x-height (68–70%), открытая апертура, различимые I/l/1, 0/O, полная кириллица.
- Классы: humanist sans = дружелюбно; geometric = минимализм, плох для длинного чтения; thin на тёмном проваливает контраст.
- Пары: контраст при общей черте; суперсемейство безопаснее.
- Шкала: база 16; размеров мало (12/14/16/18/20/24 + display); ниже 12 нельзя.
- Labels (1 строка) ≠ paragraphs (многострочные): разный line-height.
- Line-height обратно пропорционален размеру: body 140–150%, заголовки 100–130%, крупные display 100–110%. Длиннее строка = больше интерлиньяж.
- Display (hero) отдельно от заголовков продукта; на мобиле заголовок «на ступень вниз».
# Digest 02 — visual-fundamentals §5.10–7 (типографика детали, цвет, контраст, тёмная тема)

## Типографика детали
- Длина строки: десктоп 45–75 знаков, мобайл 30–40.
- Трекинг: крупные заголовки −2…−3%, мелкий капс +8…12% (до 15), body ±5% почти не трогать.
- Вес искажает размер: bold кажется крупнее. Короткие ярлыки/кикеры маленьким капсом — ок; длинный текст капсом нельзя; реплики персонажа — обычный регистр.
- Цвет/прозрачность кодируют приоритет: 100 / 85 / 60%. «Больше серого, меньше чёрного/белого — отличает профи».
- Разводить соседние тексты: вес, размер, цвет, трекинг+капс, контейнер-плашка. Eyebrow мелкий, жирный, с разрядкой, в акцентном цвете.
- Система текстовых стилей заранее, семантические имена (H1..Caption, Button, Label).
- Body по левому краю; центр — только заголовки и короткие «сценические» фразы.
- Русская микротипографика: «ёлочки», тире «—», неразрывный пробел после предлогов, без висячих слов. Каждая небрежность снижает доверие.
- Экспрессивная типографика — для 1–2 слов; отдельный шрифт для цифр допустим. Variable font для анимации веса.
- Мобайл: проще шрифт, короче текст, важное в первом экране. Размеры в rem.

## Цвет
- Структура: нейтрали (большинство) + бренд/primary (1–2) + семантика (точечно). Каждый цвет — шкала 100–900.
- Строй в OKLCH (или HSL): одинаковая светлота на ступени; хрома зависит от hue (жёлтый пик на высокой L, синий на низкой).
- Тонируй серые/чёрные оттенком бренда/сцены (5–10% overlay; chroma ~0.01–0.03). Серый на цветном фоне грязный. Не чистый #000/#fff.
- Распределение 60-30-10 для лендинга; продукт: нейтрали 90%+. Акцент ТОЛЬКО на действиях и ключевых точках; иначе перестаёт выделять (Von Restorff).
- Иконки без цвета, цвет = статус. Семантика: зелёный успех, жёлтый/оранж. предупреждение, красный ошибка/деструктив (деструктив красный даже при другом бренде).
- Состояния: hover светлее, press темнее, disabled обесцвечен.
- Гармонии: монохром/аналоговая спокойные; комплементарная сильная — один главный, второй скупо.
- Контраст WCAG AA: текст 4.5:1, крупный 3:1; мерить по отрисованным пикселям, не по токену. Бренд-цвета, не проходящие контраст, адаптировать.
- Токены с семантическими именами; режим high-contrast отдельным набором.

## Тёмная тема
- Глубина = светлота: выше слой — светлее. Шаг между слоями вдвое больше, чем в светлой (+0.04–0.06 L OKLCH).
- Не чистый чёрный (ghosting на OLED) и не чистый белый; текст 80–90%; чистый белый только для главного.
- Десатурировать акценты на 20–30%; если «дрожит» — осветлить.
- Тени чёрные ~25%, бордеры приглушены; верхняя кромка на шаг светлее = highlight.
- Не thin/light на тёмном (ореол + пропадают штрихи); regular+.
- Super-high-contrast как отдельный режим. «Лёгкость для глаз» тёмной темы НЕ доказана — это инструмент выбора, не лекарство.
- Астигматизм: белый текст «растекается» — короткие реплики, достаточный кегль/line-height, не чисто белый.
# Digest 03 — visual-fundamentals §8–10 («дорогой» вид, мобайл, процесс, споры)

## «Дорого» = меньше, но лучше
- Убирать шум: избыточные тени/glow/градиенты = любительство. Градиент только вариации одного цвета. Дефолтные тени «слишком жёсткие» — увеличить blur/убрать. «Если тень заметна первой — она лишняя».
- Удалять очевидное (декоративные стрелки, лишние лейблы, двойные бейджи).
- Консистентность: единый радиус (напр. 10), одинаковое выглядит одинаково (Back и Skip идентичны). Разнобой — главный признак любительского дизайна.
- Эффекты (стекло, blur, градиент) — на ОДНОМ слое. Тонкий градиент натуральнее плоского: радиальный градиент 1 цвета, край темнее на 5–10; обводка светлее сверху.
- Тон-в-тон: форма чуть светлее фона, кромка/блик цвета фона чуть светлее.
- Сотни маленьких анимаций в ответ на действия; анимация без функции вредна. 5 целей моушна (Riot): responsiveness, intention, awareness, consistency, physical intuition. Анимировать transform+opacity.
- Иконки: размер = line-height текста, один набор, активное = filled. Неочевидным иконкам подпись.
- Текст на изображении: линейный градиент (+progressive blur), подложка у иконок на фото; проектировать для любых фото.
- Визуалы как система: один свет/фон/стиль.
- Звук = часть «дорогого» ощущения.

## Мобильные паттерны
- Крупнее, а не мельче (база 16–17). Одно направление на секцию. Без «карточки в карточке». Таб-бар 3–4 пункта (5 предел). Thumb zone.
- Один экран = одна задача; bottom sheet когда нельзя уводить из контекста; контекстные действия.
- Проектировать от намерения пользователя и под неидеальные данные (длинные/пустые/большие). 
- Экран под стадию пользователя (новичку просто, опытному статистика).
- Пустые состояния — момент намерения, место для личности/маскота, подсказки старта.
- Ожидание: уверенное сообщение + понятное время + визуальный прогресс.
- CTA: контраст без крика; итог в кнопке («Начать · 25 мин»); пресеты вместо слайдера.
- Ввод под контекст: чипы/segmented для малого набора с дефолтом.
- Аффордансы: кликабельное выглядит кликабельным; состояния default/hover/pressed/disabled/loading; optimistic UI.
- Хаптика градуирована по важности.

## Процесс
- Реальный текст вместо Lorem; наброски ловят дыры; насмотренность (Mobbin) — процесс.
- Признаки «вайбкода»: эмодзи вместо иконок, фиолетовые градиенты, дубли KPI, бесполезные карточки, 5 тарифов, scroll reveal как единственная анимация.
- AI-UI: сначала дизайн-направление + visual system, потом секция за секцией; «AI doesn't have eyeballs» — проверять скриншотом.

## Споры (выбор)
- F-паттерн: иерархия первична, F/Z — каркас. Body 16 на мобиле. Line-height растёт с длиной строки. Одна семья шрифтов. Sans в UI. 60-30-10 для лендинга, продукт: нейтрали >85%. Thin на тёмном нельзя. В тёмной теме карточки светлее.
- Крупный перепад между уровнями страницы, малый шаг внутри блока.
# Digest 04 — attention-neuro §1–3 (как мозг распределяет внимание, захват внимания, измерение)

## Базовые механизмы
- Внимание = выбор + усиление + ПОДАВЛЕНИЕ (у СДВГ слабо именно подавление) → интерфейс убирает шум сам, не требуя игнорировать.
- Ограниченная ёмкость: прожектор (фокус/бахрома/край), зум-объектив (расширил фокус — упало качество). Один экран — один фокус.
- Bottom-up (захват стимулом: вспышка, движение, лицо) vs top-down (волевое). У СДВГ top-down слабее — не создавать своих восходящих раздражителей; вернуть можно только КРАТКИМ событием; постоянная пульсация → привыкание (habituation).
- Salience map: заметно то, что ново относительно ожиданий и релевантно задаче. Постоянное и всегда движущееся становится невидимым. Редкое событие работает, пока редкое.
- Change blindness: важное изменение нужен ОДНОКРАТНЫЙ явный сигнал. Тихая подмена не замечается.
- Многозадачности нет — переключение с ценой. Один шаг на сессию. Прерывание: ~23 мин на возврат + attention residue; не прерывать внутри сессии.
- Само присутствие телефона/чужих вкладок снижает рабочую память (репликации слабее).
- Тишина кажется некомфортной после адаптации к стимуляции; мягкий якорь присутствия вместо стимуляции.

## Захват визуального внимания
- Пре-аттентивные признаки (цвет, ориентация, размер, форма, светлота, замкнутость, движение, лица, края). Один главный «выпрыгивающий» элемент на экран; заметность — бюджет.
- Pop-out: один сильный уникальный признак → время поиска не растёт с числом элементов. Сочетание признаков → последовательный поиск (дольше). Два акцентных цвета/две «главные» кнопки ломают pop-out.
- Правило двух разниц: разница цель↔не-цели большая, разница между не-целями малая → сначала унифицируй окружение, потом подсвечивай. Дешевле glow.
- Attentional capture: самый яркий элемент должен совпадать с самым важным действием. Если ярче декор — платим «стоимостью поиска».
- Вопрос Crestodina: «Самый заметный элемент = самый ценный?» Нет → ошибка. Ясность раньше остроумия; креативный расплывчатый H1 проваливает 5-секундный тест.
- Группировка ускоряет поиск при той же плотности (5.5 с → 3.2 с).
- Контраст СВЕТЛОТЫ быстрее цветового; grayscale-тест: главное должно выделяться в ч/б. Saliency tunnel: стратегический контраст = путь.
- Изоляция/von Restorff: один элемент на пустом поле. Привлекает стимул, удерживает смысл.
- Прототипичность и низкая визуальная сложность = «красота». Атмосфера уникальна, механика стандартна.
- Первое впечатление ~50 мс; processing fluency: простое = правдивое. «Complexity signals a problem, simplicity signals a truth».
- Показывай состояние ПОСЛЕ (destination, not airplane), не скриншот работы.
- Когда все кричат — выигрывает тихое/тёплое (баннерная слепота).
- Gaze cueing: направление взгляда лица ведёт взгляд зрителя. Персонаж смотрит на то, что нужно показать.
- Z/F: суть в начало строки, не в конец. Визуальный нарратив держит дольше набора объектов.
- Тайминги: UI-отклик 200–500 мс; задержка 2–3 с = стресс (+44% пульс по вендору); мгновенный оптимистичный отклик.

## Измерение
- Say-do gap: смотреть поведение, не «нравится ли». AOI/TTFF: что получает первую фиксацию — кнопка или фон?
- Предиктивные карты внимания — дёшево для сравнения вариантов, не единственное основание.
# Digest 05 — company-teardowns §1–5 (Duolingo, Apple, Airbnb, Stripe, Spotify, Linear/Obsidian)

## Duolingo
- Ключевое поведение одно («один урок в день»); порог засчитывания дня минимальный (один урок, а не цель: +3,3% удержания на 14-й день). Серия = неприятие потери; сила реальна, но это рычаг страха.
- Серия считает касание, не пользу (GitHub убрал счётчик; Snapchat-документы); закон Гудхарта: служим серии или результату? Материальные награды подрывают внутреннюю мотивацию, похвала — нет (Деси 1999, 128 экспериментов).
- Защита: заморозка/амулет; для аудитории со стыдом — только бесплатная авто-заморозка, никаких ставок.
- Уведомления: тот же час +24 ч; 7 дней молчания → остановка с честным сообщением (+3%); мерить «вернулся и завершил», не «открыл». Пул ~100 текстов, bandit-алгоритм.
- Культура A/B: >10 000 тестов; вехи/анимации — измеримый рычаг. Главная метрика CURR (удержание текущих) даёт ×5 влияния на DAU.
- «80% от TikTok + внутренняя мотивация»; «брокколи со вкусом десерта». Конкурируют не с аналогами, а с Netflix/играми за время.
- Freemium: щедрый бесплатный тариф; НИКОГДА апселл на старте действия (эксперимент остановлен, упало удержание); сердечки/энергия = монетизация фрустрации.
- Маскот = голос всех сообщений, узнаваемый характер (пассивно-агрессивный у Duo; у «Напарника» — тёплый). Анимация персонажа: state machine + независимый слой рта (Rive).
- Редизайн дерево→путь вызвал бунт: объяснять, вводить постепенно.
- Незаметная функция = несуществующая: показывать в момент нужды голосом, не в меню.

## Apple (HIG/WWDC)
- Фича просит время/внимание/доверие → решать что НЕ включать. Принципы: purpose, agency, responsibility, familiarity, flexibility, simplicity, craft, delight.
- Agency+forgiveness: лёгкий undo; подтверждение только на необратимом; не вести по одному пути.
- Разрешения/данные просить в момент ценности с объяснением.
- Familiarity: одинаковое выглядит и ведёт себя одинаково; метафора средней абстрактности.
- Simplicity ≠ minimal: иногда простота = добавить контекст («где я, сколько осталось»).
- Craft: «дешёвый» софт чувствуется сразу; Delight — не конфетти в конце, а целевая эмоция + основы.
- Айв: мы различаем больше, чем можем сформулировать; полировка невидимого.
- Три вопроса экрана: где я? что можно сделать? куда дальше? Главное — самое заметное. Прищур-тест.
- Таб-бар = навигация, не действия. 3 таба. Прогрессивное раскрытие + пространственная непрерывность (shared-element переходы).
- Формы: squircle + концентричность (inner radius = outer − padding). Капсулы у края.
- Liquid Glass: в покое тих, оживает от касания; tint только для функциональной роли («если тонировано всё — ничто не выделяется»); цвет в контенте, не в контролах; Reduce Motion/Transparency/Contrast.
- Иерархия раскладкой, не декором; scroll edge вместо разделителя; символ только если ясен, иначе текст.
- iPhone Duo: контролы в зоне большого пальца; без пиксельных констант.
- UX-текст Apple: без «просто/легко/быстро», без «упс»/«извините»; лид с «зачем»; word list (один термин — одно слово); имена нейтральны при нуле.
- Assistive Access: меньше опций и шагов, не зависимые от времени действия, всегда путь назад.
- Пульсирующий контур первого действия — допустим как одноразовая подсказка (контингентный).
- Живое движение дёшево: сложение 2–3 циклов с разными периодами (7/11/23 с) — не наступает привыкание.
- Rubber-band/физика жестов не требуют обучения; крупные изменения — постепенно.

## Airbnb / Stripe / Spotify / прочие
- Проектировать для крайних пользователей; «делай то, что не масштабируется»; 10-звёздочный опыт; всегда показывать «что дальше», предзаполнять; цель — вернуть человека в жизнь, не держать на платформе; глубина (тень) должна что-то поднимать, иначе шум.
- Stripe: качество как система; реальные компоненты и данные в прототипах; стайлгайд текстов + автопроверка; лимиты на сервере.
- Spotify: «главный квест» vs побочные; различимость типов по форме; предсказуемые размеры; Главная ощущается «домом»; зона большого пальца; одна иконка — одно действие; автономная говорящая фича обязана иметь skip/«меньше такого»/выключение; цвет как состояние.
- Linear как эталон против «AI slop»: сравнивать численные токены (tracking, radius, elevation, частота акцента) с эталоном.
- Obsidian: не «магическая кнопка AI везде»; хорошее трение.
